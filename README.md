# trabajos-encontrar

Skill en español para comparar plataformas de empleo, encontrar hasta cinco vacantes activas y preparar un CV adaptado a cada una. La búsqueda parte de tu ubicación, modalidad, experiencia y preferencias sobre el tipo de trabajo que quieres hacer y el que deseas descartar.

## Instalación

```bash
npx skills add iamFear/trabajos-encontrar --skill trabajos-encontrar
```

## Uso

Pide a tu agente que use `trabajos-encontrar`. Por ejemplo, puedes escribir:

> Usa trabajos-encontrar para buscar puestos remotos de operaciones desde Colombia. Me gusta coordinar procesos y atender clientes. Descarta cargos que incluyan llamadas en frío. Usa el CV que adjunté.

Usa un agente con acceso web para verificar vacantes activas y con generación de archivos para recibir los CV en DOCX u otro formato solicitado.
