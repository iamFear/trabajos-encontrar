# trabajos-encontrar

Skill en español para comparar plataformas de empleo, encontrar hasta cinco vacantes activas y preparar un CV adaptado a cada una. La búsqueda parte de tu ubicación, modalidad, experiencia y preferencias sobre el tipo de trabajo que quieres hacer y el que deseas descartar.

## Instalación

Reemplaza `TU-USUARIO/TU-REPO` por el nombre del repositorio público de GitHub.

```bash
npx skills add TU-USUARIO/TU-REPO --skill trabajos-encontrar
```

## Uso

Pide a tu agente que use `trabajos-encontrar`. Por ejemplo, puedes escribir:

> Usa trabajos-encontrar para buscar puestos remotos de operaciones desde Colombia. Me gusta coordinar procesos y atender clientes. Descarta cargos que incluyan llamadas en frío. Usa el CV que adjunté.

Usa un agente con acceso web para verificar vacantes activas y con generación de archivos para recibir los CV en DOCX u otro formato solicitado.

## GitHub y skills.sh

1. Para un repositorio dedicado, sube `SKILL.md` y `README.md` a su raíz. Si agregas la skill a un repositorio que agrupa varias, ubícala en `skills/trabajos-encontrar/`.
2. Comprueba desde la CLI que el repositorio público expone la skill.

   ```bash
   npx skills add TU-USUARIO/TU-REPO --list
   ```

3. Instala la skill desde el repositorio público con el comando de instalación. Skills.sh agrega entradas automáticamente a partir de instalaciones registradas por su CLI con telemetría habilitada. Después, comprueba si aparece en `https://skills.sh/TU-USUARIO/TU-REPO/trabajos-encontrar`.
